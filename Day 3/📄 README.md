# 🏦 ATM Management System

## 📌 Description

A menu-driven ATM application built using Python. Users can check their balance, deposit money, withdraw money, and view transaction history.

---

## 🚀 Features

- Check Balance
- Deposit Money
- Withdraw Money
- Transaction History
- Input Validation
- Menu-Based Interface

---

## 🛠 Technologies

- Python 3

---

## 📚 Concepts Used

- Functions
- Loops
- if-elif-else
- Lists
- Variables
- User Input

---

## ▶ How to Run

```bash
python ATM_System.py
```
