# 💰 Expense Tracker (Python)

## 📌 Description

A menu-driven Expense Tracker built using Python. It allows users to store and manage daily expenses using file handling.

## 🚀 Features

- Add Expense
- View All Expenses
- Calculate Total Expense
- Search by Category
- Delete Expense
- Persistent Storage using Text File

## 🛠 Technologies

- Python 3

## 📚 Concepts Used

- Functions
- Loops
- Lists
- File Handling
- Exception Handling
- String Formatting

## ▶ How to Run

```bash
python Expense_Tracker.py
