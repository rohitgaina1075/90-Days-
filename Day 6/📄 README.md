# 📞 Contact Book

## Description

A Contact Book application built using Python and Object-Oriented Programming (OOP). It stores contacts in a text file and supports CRUD operations.

## Features

- Add Contact
- View Contacts
- Search Contact
- Update Contact
- Delete Contact
- Count Contacts

## Concepts Used

- Python OOP
- File Handling
- Exception Handling
- CRUD Operations
- Functions

## Run

```bash
python Contact_Book.py
```
