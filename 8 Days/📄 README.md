# 📚 Library Management System

## Description

A console-based Library Management System built with Python using Object-Oriented Programming and CSV file handling.

## Features

- Add Book
- View Books
- Search Book
- Update Book
- Delete Book
- Issue Book
- Return Book
- Count Books

## Technologies Used

- Python
- OOP
- CSV Module
- File Handling
- Exception Handling

## How to Run

```bash
python library_management.py
```
