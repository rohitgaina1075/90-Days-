# 🎓 Student Result Management System

## 📌 Description

A beginner-friendly Python project that calculates a student's result based on marks entered for five subjects.

---

## 🚀 Features

- Add Student Name
- Enter Marks
- Calculate Total Marks
- Calculate Percentage
- Assign Grade
- Pass/Fail Result
- Input Validation
- Clean Output Format

---

## 🛠 Technologies

- Python 3

---

## 📚 Concepts Used

- Variables
- Functions
- Lists
- Loops
- if-elif-else
- Input Validation
- String Formatting

---

## ▶ How to Run

```bash
python main.py
```

---

## 📊 Grade System

| Percentage | Grade |
|------------|-------|
| 90+ | A+ |
| 80–89 | A |
| 70–79 | B |
| 60–69 | C |
| 50–59 | D |
| Below 50 | F |
